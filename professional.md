## Step 0: Create the report file

Before doing anything else:
1. Check whether `professional-audit.md` exists in the project root.
2. If it does not exist, create it.
3. If it already exists, clear it and start fresh.
4. Add the date and a one-line summary of my task at the top.

Write everything to `professional-audit.md`, not to the chat. Update it as each step is completed. Do
not wait until the end.

## Task

I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I’m not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

## Updating the report

1. After each of the four answers, add it to `professional-audit.md` under its own heading.
2. Add the rewritten prompt under a **Rewritten prompt** heading.
3. While executing the rewritten prompt, add each step's results under an **Execution** heading as
   that step finishes, including what you checked and any test or verification output.
4. Finish with a **Result** section: the solution delivered, and how it was verified against the
   check named in answer (4).

## Rules

- Create `professional-audit.md` first, before any other step.
- Update `professional-audit.md` after each step; every step must have its results recorded.
- If you revisit an earlier answer or step, update its entry instead of adding a duplicate.
- Do not invent results. Mark anything unconfirmed as **Needs Verification**.
